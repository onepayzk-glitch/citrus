# Citrus 1.x 规划（作者：假宝玉）

> 定位：macOS 菜单栏「拖拽即用」的文件转换与轻工具箱，组装版本（不捆绑外部引擎，用时检测并帮助安装），
> 本地处理、无账号、无遥测。GPL-3.0-only，源码公开，接受打赏但不锁功能。

## 0. 当前基线（1.0）

- 275 条转换路由、26 个 Tangerine 工具 + 读二维码、6 个文件动作、⇧/⌘/⌃ 轮盘；
- 中英双语（默认跟随系统）、首启引导、声音/触感、Float、拖拽修饰键重映射；
- 组装依赖：LibreOffice / FFmpeg / Pages 用时检测 + 安装帮助；
- 反馈入口：作者 **假宝玉**、GitHub `onepayzk-glitch`、邮箱（运行时拼装，界面不直接展示明文）。

## 1. 版本节奏与里程碑

| 版本 | 主题 | 关键交付 | 预估 |
|---|---|---|---|

| **1.3** | 有趣功能 | 柑橘伙伴（Notch 小角色表情/完成庆祝动画）、批量完成彩纸/音效、节日主题、拖拽小彩蛋、本机使用统计（仅本地、可关闭） | 6–10 人日 |
| **1.4** | 效率 | 配方 Recipes（多步流水线：缩放→压缩→转换）、监视文件夹、快捷指令/Shortcuts、拖到菜单栏图标、失败重试与队列管理 | 12–18 人日 |

## 2. 个性化设置能力（1.2 详细）

| 设置项 | 说明 | 默认 |
|---|---|---|
| 菜单栏图标 | 经典柑橘 / 单色模板 / 极简圆点 / 自定义 PNG | 经典 |
| 强调色 | 6 套预设 + 自定义取色，跟随系统强调色 | 柑橘橙 |
| 轮盘外观 | 半径、透明度、玻璃/纯黑、图标或文字优先 | 跟随主题 |
| 工具排序/隐藏 | 拖拽排序、按类别隐藏不用的工具（仍可通过菜单搜索） | 全部显示 |
| 输出命名模板 | 占位符：`{name}` `{tool}` `{date}` `{index}`；支持中文/英文默认模板 | `{name} {tool}` |
| 按格式默认参数 | 每个目标格式记住质量/尺寸/码率（例如 WebP 固定 80%） | 全局默认 |
| 声音包 | 系统音 / 柑橘音效（自制）/ 静音；音量与触发点 | 系统音 |
| 动效 | 减少动效（跟随系统）、轮盘弹簧动画强度 | 跟随系统 |
| 预设与配方 | 保存「一步完成」的常用组合，拖拽后直接执行 | 无 |

## 3. 有趣功能（保留清单，1.3）

1. **柑橘伙伴**：Notch 下方的小橘子角色，随任务状态变化（等待/工作/完成/失败），可关闭。
2. **庆祝反馈**：批量完成时彩纸动画 + 轻音效（可在设置关闭；不阻塞操作）。
3. **节日主题**：春节/中秋/万圣节等限时轮盘配色与图标（本地内置，不联网）。
4. **小彩蛋**：连续拖拽、特定组合格式时触发趣味文案/音效；不影响主流程。
5. **本机统计**：本周处理文件数、节省体积、最常用工具（仅本地存储，可一键清除）。
6. **拼贴/贴纸模板**：给图片拼贴工具增加几套「社交尺寸」模板与贴纸素材（自制或开源素材）。

> 原则：有趣但不打扰；所有「趣味」默认可关闭；不收集数据、不联网。

## 5. 反馈与隐私

- 反馈入口：About 页「反馈问题」、菜单栏「反馈问题…」；支持邮件与 GitHub。
- 「复制诊断信息」只含：App 版本、macOS 版本、架构、界面语言、可选引擎（LibreOffice/FFmpeg/Pages）是否安装；**不含**文件名、路径、账号、邮箱。

- 发布前建议：Developer ID 签名 + 公证；仓库公开（`onepayzk-glitch`），Issues 作为公开反馈渠道。
